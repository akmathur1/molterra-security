# Vault — 54 attacks

Generated by `cargo run --bin redteam -- --write`; do not edit. Index: [`../ATTACKS.md`](../ATTACKS.md).

Target: a byte-faithful mirror of `backend/src/integrations/crypto.rs` — AES-256-GCM with a random 96-bit nonce, stored as `base64(nonce ‖ ciphertext ‖ tag)`, no associated data. The attacker holds write access to the `integration_accounts` table but not the key. Hardened: the same cipher with the row's (org, account, field) bound in as AAD. `tests/mirror_tests.rs` pins the mirror to the shipped wire format.

Shipped: 49 blocked, 5 landed. Hardened: 53 blocked, 1 landed.

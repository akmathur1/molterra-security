# Attack dossier

Every attack in the corpus, both verdicts, with the evidence behind each. Generated by `cargo run --bin redteam -- --write`; do not edit. The full offense/defense record for each row — payload as the detector sees it, function called, value returned — is in the per-family pages under `attacks/`. `FINDINGS.md` is the same data grouped by technique; `attacks.json` is this page as data.

**How to read a row.** *Shipped* is the code on `main`, called for real. *Hardened* is the same call with the layer in `src/defenses/` in front of it — proposed, not deployed. `blocked` means the attacker got nothing; `LANDED` means the payload reached the place it was aimed at or the secret came out. Payloads are printed with every non-ASCII code point escaped as `⟨U+XXXX⟩`, because the point of half of them is that you cannot see them.
